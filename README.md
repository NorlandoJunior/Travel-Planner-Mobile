# Travel Planner Mobile

## Overview

I am working to improve my programming skills by creating practical software projects and becoming more comfortable with modern development tools such as React Native, Expo, TypeScript, Git, GitHub, and Visual Studio Code. My goal is to continue learning software development concepts and building a strong foundation as a software engineer.

This software is a simple mobile travel planning application that allows users to create, view, edit, and delete trips. Users can manage information such as destination, travel dates, budget, and notes.

The purpose of creating this software was to practice mobile application development, user interaction, navigation between multiple screens, form validation, and data persistence using local storage.

The application was developed using React Native and Expo. Expo Router was used to navigate between multiple screens, including the home screen, add trip screen, and edit trip screen.

The project also demonstrates React Native features including components, state management, user input handling, form validation, asynchronous functions, navigation, and local data storage using AsyncStorage.
